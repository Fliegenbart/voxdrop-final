# Voice Samples für XTTS v2

Lege hier die Audio-Samples für das Voice Cloning ab:

## Erforderliche Dateien

- `male_sample.wav` - Männliche Stimme (15-30 Sekunden)
- `female_sample.wav` - Weibliche Stimme (15-30 Sekunden)

## Anforderungen an die Samples

- **Format:** WAV (bevorzugt) oder MP3
- **Länge:** 15-30 Sekunden klare Sprache
- **Qualität:** Kein Hintergrundrauschen, keine Musik
- **Inhalt:** Normales Sprechtempo, klare Aussprache
- **Sample Rate:** 22050 Hz oder höher

## Tipps für gute Ergebnisse

1. Ruhige Umgebung ohne Echo
2. Gleichmäßige Lautstärke
3. Natürliches Sprechtempo
4. Keine langen Pausen
5. Verschiedene Satztypen (Fragen, Aussagen)
